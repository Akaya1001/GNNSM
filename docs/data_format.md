# Data format

A **case** is one building/installation, stored as a directory:

```
<dataset>/<split>/case_XXXX/
├── meter.parquet     # the (T, N) consumption time series
└── hierarchy.json    # metadata + ground-truth parent/child tree
```

`<split>` is `train`, `val`, or `test`. Data is generated by
`scripts/generate_data.py` and is **never committed** (see `.gitignore`).

## `meter.parquet`

A table with:

* a `timestamp` column (datetime), and
* one `float` column per meter, named by the meter id.

Loaded as a `(T, N)` matrix (T timesteps, N meters); the timestamp column is
dropped. See `meterhierarchy.data.case_io.load_case`.

## `hierarchy.json`

```json
{
  "case_id": "case_0001",
  "n_meters": 23,
  "n_roots": 2,
  "max_depth": 4,
  "time_resolution_minutes": 15,
  "n_timestamps": 35040,
  "approx_sum_children_equals_parent": false,
  "meters": [
    {"id": "meter_root_1", "parent_id": null, "children": ["meter_a", "meter_b"]},
    {"id": "meter_a", "parent_id": "meter_root_1", "children": []}
  ]
}
```

The loader builds the ground-truth edge set from `meters[].parent_id`
(`(parent_index, child_index)` tuples). `approx_sum_children_equals_parent`
flags whether the hierarchy is additive (parent ≈ sum of children) or has a
hidden/unmetered load; it drives the non-additive case weighting and the latent
head during training.

## In-memory representation

`load_case(folder)` returns
`{data (T,N), names, true_edges, n_meters, meta, case_id}`.
`build_case_features(raw)` adds the model inputs:
`edge_feats (N,N,58)`, `node_feats (N,15)`, `pe (N,8)`, and the labels
`labels (N,N)`, `root_labels (N,)`, `latent_labels (N,)`.
